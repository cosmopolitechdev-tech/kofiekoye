# Kofiekoye

**The Solution to 'Homework for the homework giver'** — an automatic and customizable Scheme of Learning &
Lesson Plan generator for Junior High School (Basic 7–9) teachers in Ghana, aligned to the NaCCA Common Core
Programme curriculum. Exports editable Word documents and print-ready PDFs.

- **Website:** https://kofiekoye.cosmopolitechsolutions.com
- **Download the latest version (Windows 10/11, 64-bit):**
  [Latest release](https://github.com/cosmopolitechdev-tech/kofiekoye/releases/latest). Each release's notes
  list what changed.

The download is free and runs in Demo Mode; a one-time licence unlocks full documents.

## About this repository

This repository holds only the product web page (`index.html` and `images/`), served by GitHub Pages at the
address above. Installers are attached to the [Releases](https://github.com/cosmopolitechdev-tech/kofiekoye/releases).
The application's source code is not stored here.
